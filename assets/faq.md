# Xpenzi (Spendwise) - Guide and FAQ

Welcome to Xpenzi! Below you'll find answers to some common questions.

## 1. How do I add a new transaction?
Tap the **+** button at the bottom of the screen. You can select the type of transaction (Expense, Income, Transfer) at the top of the Add Transaction page.

## 2. Where did the Action Bar go?
The Expense, Income, and Transfer selections have been unified into a single easy-to-use tab selector on the **Add Transaction** screen to keep your home interface clean and minimal.

## 3. How do I customize the appearance?
Head to **Settings -> Theme & Style**. From there you can change your accent color, enable Dynamic Color (Material You) on Android, switch to Dark Mode, and adjust icon styles.

## 4. How do I backup my data?
Navigate to **Settings -> Import & Export -> Backups**. You can export your entire database securely.

## 5. Is Xpenzi open source?
Yes! You can view the source code and contribute on our [GitHub Repository](https://github.com/linson-cv/Spendwise-Expense-Tracker).

## Need More Help?
If you have any further questions, bugs to report, or feature requests, please submit feedback via the **Settings -> About -> Feedback** button, which will open a draft directly to the developer!
